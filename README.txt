BETHANY CAFE - RECREATED VS CODE PROJECT

WHAT WAS UPDATED
- Replaced the repeated menu photos with 49 distinct food-product images.
- Each menu image is assigned to its corresponding menu item ID.
- The Buffalo Wings item (menu item #48) has a dedicated buffalo-style chicken wings photo.
- Preserved the existing café logo, page background, menu names, prices, and website features.
- Kept the existing GCash/Maya QR upload flow in the Admin Dashboard.

HOW TO RUN
1. Extract this ZIP file.
2. Open the BethanyCafe_Final folder in Visual Studio Code.
3. Open index.html using Live Server (recommended), or open index.html in a browser.
4. For the demo admin login, use:
   Email: admin@bethanycafe.com
   Password: admin123

GCASH / MAYA PAYMENT QR
- Log in to Admin, then upload the café's official GCash QR image (and Maya QR if used).
- The uploaded QR is saved in this browser's localStorage for this demo.
- Do NOT use a generated/sample QR for real payments. Only upload the official QR from the café's GCash app/account.
- Orders and admin data are also stored locally in this browser; this is a front-end demo, not a production server.

IMPORTANT
- Menu prices and product names are retained from the original project.
- Food photos are illustrative generated product photos and may not exactly match the café's actual plating.
- To deploy for real customers, connect the app to a secure backend/database and implement server-side authentication and order handling.
